# 作業実績集計ツール on Google カレンダー

## やりたいこと

1. **Google カレンダー** に作業した時間を登録します
2. 集計する条件を指定します
  - 指定する条件
    - 集計期間（集計開始日と集計終了日）
    - 集計対象のタグ（ハッシュタグ？タイトル？ここはベストプラクティスを参考に提案してほしい）
    - 集計対象のカレンダー名
3. 集計を開始
4. 結果は **Google スプレッドシート** に テーブル形式 で出力する

## このツールのユーザのペルソナ

- **非IT系** でシステムに詳しくないフリーランス
- 日々の作業実績をクライアントに報告する必要がある
- Google Cloud を自分で設定することは出来ない
- Google カレンダーをブラウザで操作して予定を登録することならできる
- GAS の操作は慣れていないので、丁寧に、ステップバイステップの説明書（ドキュメント）が必要

## 動作環境

- ブラウザで利用できるように Google スプレッドシート で動作できる **Google App Script (GAS)** で作ります
- ただし、 **非エンジニアでも使えるようにしよう！**

## 出力データに含める情報

- 作業開始時間（カレンダーの予定の開始時間）
- 作業終了時間（カレンダーの予定の終了時間）
- 作業した内容（これはカレンダーの詳細欄とかに記入しておく）
- 合計作業時間（時間単位）
