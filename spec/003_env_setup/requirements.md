# 環境切り替え設定の要件

clasp を使用した Google Apps Script (GAS) 開発において、開発用と本番用の環境を安全かつ簡単に切り替えられるようにする。

## 背景
- 本番用のスプレッドシートと GAS プロジェクトが公開された。
- 開発中の変更が誤って本番環境に反映されないよう、明示的に環境を切り替える仕組みが必要。
- セキュリティ上の理由から、スクリプトIDを含む設定ファイルは Git リポジトリに含めない。

## 要件
- 開発用と本番用のスクリプトIDを適切に管理できること。
- コマンド一つで環境（`.clasp.json`）を切り替えられること。
- `.clasp.json` などの設定ファイルが Git にコミットされないようにすること。
- 他の開発者がセットアップしやすいよう、テンプレートやドキュメントを提供すること。
