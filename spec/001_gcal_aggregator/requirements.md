# 要件定義：Googleカレンダー作業実績集計ツール

このドキュメントでは、Googleカレンダーに入力した予定を自動で集計し、スプレッドシートにまとめるツールの目的と機能を説明します。

## 1. 目的
フリーランスの方が、日々の作業時間を簡単に集計し、クライアントへの報告をスムーズにできるようにします。
難しい設定や操作を必要とせず、普段使い慣れているGoogleカレンダーとスプレッドシートだけで完結することを目指します。

## 2. 対象となるユーザー（ペルソナ）
*   システム設定やプログラミングに詳しくないフリーランスの方
*   Googleカレンダーで予定を管理している方
*   作業実績を時間単位で集計し、表形式でまとめたい方

## 3. ユーザーができること
1.  **カレンダーに予定を入れる**
    *   いつも通りGoogleカレンダーに作業内容を登録します。
    *   集計したい予定には、タイトルに `[実績]` と入力します。
2.  **集計の条件を決める**
    *   スプレッドシートの「設定」欄に、いつからいつまでの分を集計したいか日付を入力します。
3.  **ボタンを押して集計する**
    *   スプレッドシートのメニューから「集計を実行する」を選びます。
4.  **結果を確認する**
    *   スプレッドシートに、作業日、開始時間、終了時間、内容、合計時間が一覧で表示されます。

## 4. 機能要件（ツールができること）
*   **カスタムメニュー機能**: スプレッドシートの上のメニューに、専用の操作メニューを表示します。
*   **設定読み取り機能**: スプレッドシートに入力された「開始日」「終了日」「カレンダー名」「キーワード」を読み取ります。
*   **カレンダー検索機能**: 指定された期間とキーワードに一致するカレンダーの予定を探し出します。
*   **時間計算機能**: 予定の開始から終了までが何時間（何分）だったかを計算します。
*   **結果出力機能**: 探し出した予定を、スプレッドシートの「集計結果」シートにきれいに並べて書き出します。

## 5. 非機能要件（使いやすさ・安心のための工夫）
*   **かんたんコピー配布**: スプレッドシートをコピーするだけで、誰でもすぐに使い始められるようにします。
*   **分かりやすいエラー表示**: もし日付の入力が間違っていたりした場合、優しい言葉で何が違うかをお知らせします。
*   **丁寧な説明書**: 初めて使うときの「承認（許可）」の手順を、画像や図を使って丁寧に説明します。

## 6. 集計のルール
*   **集計対象**: カレンダーの予定のタイトルに特定のキーワード（初期設定は `[実績]`）が含まれているもの。
*   **計算単位**: 時間単位（例：1時間30分なら 1.5時間）として計算します。
*   **出力項目**: 
    1.  日付
    2.  開始時刻
    3.  終了時刻
    4.  内容（カレンダーのタイトル）
    5.  詳細（カレンダーの説明欄）
    6.  作業時間（時間）
