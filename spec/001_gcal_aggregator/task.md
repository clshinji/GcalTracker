# タスクリスト：Googleカレンダー作業実績集計ツール

このタスクリストは、開発の進み具合を管理するためのものです。

## フェーズ1：SDD作成と合意
- [x] 要件定義書 (`requirements.md`) の作成
- [x] 基本設計書 (`design.md`) の作成
- [x] タスクリスト (`task.md`) の作成
- [ ] 開発者によるSDDの確認と合意

## フェーズ2：スプレッドシートの準備とメニュー表示
